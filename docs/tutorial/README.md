# Tutorials

Ordered lessons you follow at your terminal, on a sandbox of your own: two GitHub repositories,
built from this repository's `sandbox/` folder with your names. Each lesson builds on the one
before, and each shows the commands and what you should see.

There are two tracks. Do them in order.

| Track | What you learn | Needs |
|---|---|---|
| [1. ynf on its own](ynf/README.md) | The outer loop with nothing else involved: lanes, tickets becoming draft pull requests, decisions you can replay, running unattended, and what happens when things go wrong. Every lane runs a command, so there is no model and no spend. | GitHub, Terraform, Docker |
| [2. The factory](factory/README.md) | ynh and ynm stitched in by hand, one join at a time: a harness lane, a contained agent run, model and cost, failures remembered and reflected on, shared memory, and all three in one image run as a job. | Track 1, ynh, ynm, an Anthropic API key |

Each tool also has tutorials of its own, for using it alone:
[ynh](https://github.com/eyelock/ynh/tree/develop/docs/tutorial) and
[ynm](https://github.com/eyelock/ynm/blob/main/docs/tutorial/README.md). You don't need them first.
